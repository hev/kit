## 0.6.2

November 8, 2026 — [release and downloads](https://github.com/hev/kit/releases/tag/v0.6.2).

- **Members add and remove repos.** An owner lists the organizations repos may
  come from (`[admission] add_from`) and grants `repos` per member
  (`hev nodes accept --allow repos`, `hev nodes allow|deny`). Members run
  `hev admission ls|add|remove`. The host clones with its own credentials,
  with time limits, no prompts, no LFS fetches and no redirects. See
  [Admission](/docs/admission#let-members-add-repos).
- **`hev skills setup`.** One step after install or join sets up hev's skills
  for Claude Code, Codex, pi and OpenCode, plus a team's skill sources,
  without starting anything. It prints every folder it touches. Members get
  `hev-member` in place of the owner-only skills. Hosts set `--role host`.
  Codex, pi and OpenCode share one copy in `~/.agents/skills`.
- **Run notices for members.** A host holds notices for members' runs, since
  it can't reach their laptops. `hev dispatch notices pull [--watch]` fetches
  them into the local peers inbox, once each.
- **OpenCode capture.** hevd captures OpenCode 2.x and 1.x sessions from its
  database, read-only and only once a reply is finished. An unrecognised
  database layout shows in `hev s` instead of being skipped.
- **Shared hosts docs.** Owner and member roles, and a new
  [Join a host](/docs/join-a-host) guide for members.

## 0.6.1

November 6, 2026 — [release and downloads](https://github.com/hev/kit/releases/tag/v0.6.1).

- **Shared hosts with `hev nodes`.** Invite a teammate to a host you run. Their
  key can only run dispatch, runs record who sent them and who asked for the
  work, and `hev nodes remove` revokes access.
- **Dispatch queue.** A full host queues orders first in, first out instead of
  refusing them. `hev dispatch ls` shows position and age; `stop` removes a
  waiting order.
- **`hev watch`.** Deterministic watches on tracker statuses and an email inbox,
  each rule with its own instructions. Source checks (a human assigned it; an
  allowed, authenticated sender) can't be configured away. `hev intake` is an
  alias.
- **`hev secrets`.** A memory-only cache in the daemon for service-account
  secrets: fewer reads, backoff on rate limits, and `hev secrets status`.
- **Skill sources.** `hev skills sync` installs a team's own skills repo,
  pinned, for Claude Code, Codex and shared agent skills.
- **Native peers.** `hev peers` works with the same inbox files as before and
  delivers to runs over restricted keys.
- **hev layer naming.** `HEVLAYER_API_KEY`, `HEVLAYER_ENDPOINT` and
  `HEVLAYER_NAMESPACE`. The old `LAYER_*` names still work, with a warning. A
  daemon no longer falls back to a built-in 1Password reference: set
  `HEVLAYER_API_KEY` or `HEVLAYER_API_KEY_OP_REF`.

## 0.6.0

November 5, 2026 — [release and downloads](https://github.com/hev/kit/releases/tag/v0.6.0).

Tools for building a team's software factory: trace capture on each host,
dispatch to shared hosts, and repo admission.

- **Orchestrators.** Opt-in agents with scoped authority, bounded budgets,
  fresh rounds and durable checkpoints. Phase 2 adds visibility and source rules.
- **Dispatch.** `hev dispatch ORDER.md` sends an order to a configured host
  over SSH, runs a supervised worker in its own worktree and branch, and
  keeps a run record under `~/dispatch/NAME/`. Includes `hosts`, `ls`,
  `show`, `logs`, `stop`, `rework` and `clean`.
- **Inline orders and messages.** `hev dispatch run` writes an order from the
  command line and picks a host. `say` sends a message to a live run, and
  `attach` opens its tmux session.
- **Browser validation.** Orders with `validation: browser` get a validator on
  a separate host that checks each Acceptance item and returns a verdict.
  `validate` and `rework --from-validation` drive it by hand.
- **Per-host launch settings.** `workspace`, `harness_wrapper` and
  `config_path` on each `[hosts.NAME]` entry.
- **Repo admission.** A host's `[admission] repos` list limits the repos it
  will run, checked against the clone's origin. See [admission](/docs/admission).
- **Board.** `hev board`, shared searchable memory for agents across sessions
  and hosts.
- **Plugins.** `hev NAME` runs `hev-NAME` from PATH.
- **Windows capture.** Native transcript capture and a Task Scheduler daemon
  lifecycle with `hev daemon install`.
- **Summaries and skills.** Better session summaries, chunk role and block
  type indexing, and skill capture across harnesses with a dashboard filter.

- **Native peers.** Session and dispatch discovery, reads, sends, inbox consumption
  and ACK, plus group chats. SSH remains the default; opt-in authenticated hevd
  enqueue supports outbound-only senders. Inventory and reads still use SSH.
- **Amendments.** `hev dispatch amend` replaces an order while retaining its
  branch, PR and history, including host moves.
- **Repeating orders.** `every`, `until` and `max_lifetime` schedule fresh
  sessions in one worktree without overlapping rounds.
- **Expediting.** Optional `hev expedite` follows a snapshot of runs with
  explicit review or merge-on-green authority.
- **Target capacity.** Receiving hosts own their cap. Senders can lower it
  for a request but cannot raise it. Admission also checks rework and moves.
- **Installation.** The `hev` tap formula and release pipeline cover macOS
  and Linux on AMD64 and ARM64, plus Windows AMD64 archives. Linux capture
  has a systemd user service. These artifacts are available in the 0.6.0 release.
- **Bundled skills.** Version stamps and `hev skills check` / `sync` report
  drift and repair installed skills while preserving local edits by default.
- **Board reads.** `hev board serve --read-only` rejects write routes.
- **CLI fixes.** Help, overview and trace commands match the current command
  surface. Resource-backend commands remain in the legacy group.

## 0.5.1

October 25, 2026

- Stats in the dashboard loads on its own, with compact totals and chart data.
- Bare `hev` prints a read-only overview of nodes, orders and peers.
- The resource-first CLI: `api-resources`, `apply`, `get`, `describe` and the
  `nodes`, `orders` and `runs` groups. These are now [legacy](/docs/cli#legacy).
- Capture keeps instruction versions, session commit, PR and workflow
  evidence, and native PI traces.

0.5.0 was tagged but never published. Its release build used a Go version
older than the module requires.

## 0.4.0

October 2, 2026

- Secrets are scrubbed from transcripts before they are written to the
  archive or sent to the summary model.
- Existing archives are scrubbed once on the first run after upgrading.
- `hev join`, `hev leave` and `hev open` for invited hosted archives.
- Exact phrase search in the dashboard.

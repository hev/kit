---
title: "Field Kit sign-in"
description: "Sign this machine into Field Kit."
group: "Start"
---

Create a named API key in Settings at https://kit.hevmind.com, then:

```sh
brew install hev/tap/hev
export HEV_API_KEY=…
```

No browser sign-in is required. `HEV_API_KEY` wins over the saved config key.
The service defaults to `https://kit.hevmind.com`; override it with
`HEV_KIT_SERVICE`. First use saves a verified key in the private config (0600)
so the daemon can use it without the shell environment. Restart a daemon
already running when you change the key.

`hev login` optionally verifies and stores a key from env, stdin or `--key`.
Use `hev login --import` to copy existing history. The legacy browser and
invite flow remains available with `hev login --browser --code CODE`.

`hev logout` removes the stored key. An exported `HEV_API_KEY` still applies;
unset it to stop using it. Revoke keys in Settings. A refused key never clears
stored credentials or drops queued captures.

Field Kit admins configure the team's app under **Settings → Mobile app**.
Those settings write `kit-dot.json`. On Pro Kit, supply this file directly to
your dot. [Try the mobile app demo](/configure).

The app is an installable, voice-first web app (PWA), built on hev/dots.
Field Kit hosts it for your team as part of [sign-up](/pricing#start).
Pro Kit runs it in your cloud next to hev layer. [Compare plans](/pricing).
The generic template is being built; this page documents its v1 contract.

## Fields

All fields are required. Defaults below are the initial settings. Unknown fields are rejected. The downloadable
[JSON Schema](/schemas/kit-dot.schema.json) defines the same rules used by the app.

| Field | Type | Default | Validation and meaning |
| --- | --- | --- | --- |
| `version` | integer | `1` | Exactly `1`. A future incompatible format uses a new version. |
| `name` | string | `"kit dot"` | 1–80 characters, at least one non-whitespace character. App name. |
| `wordmark` | array of strings | `["kit", "dot"]` | Exactly two parts, each 1–80 characters with non-whitespace content. |
| `operator` | string | `"Your name"` | 1–80 characters with non-whitespace content. What the dot calls you. |
| `color` | string | `"#e25822"` | A `#` and exactly six hex digits. Accent colour. |
| `voice` | string | `"Algenib"` | One of `Algenib`, `Kore`, `Puck`, `Aoede`. Gemini Live voice for spoken replies. |
| `logins` | array of strings | `["you@example.com"]` | At least one unique email, up to 254 characters each. Must contain a non-empty local part, `@`, and a domain containing a dot; no whitespace. Allowed sign-ins. Replace the example before use. |
| `hosts` | array of strings | `[]` | Optional host list, unique names up to 253 characters. Start with a letter or digit, then letters, digits, dots, underscores or hyphens. Names come from `hev dispatch hosts`. |
| `icon` | object or null | `null` | `null` selects the default hard-hat hev head. An object requires exactly `file` and `sha256`. |
| `icon.file` | string | `"icon.png"` when uploaded | Exactly `icon.png`, beside the config. The original uploaded PNG. |
| `icon.sha256` | string | computed when uploaded | 64 lowercase hex digits: SHA-256 of the original PNG bytes, not a resized image. |
| `acts` | object | `{"live": false}` | Requires only `live`. |
| `acts.live` | boolean | `false` | Off is dry-run. Enabling live acts is a separate, deliberate switch. Each action still needs a spoken read-back and a yes. |

Settings trim surrounding whitespace and omit blank email and host lines.
Voice preview in the public demo is a written sample, not synthesized audio.

## Icons

Give the dot one square PNG, at least 512 × 512 pixels. The icon picker checks
PNG signature, decodes the image, rejects non-square and undersized images,
and hashes its original bytes. Keep `icon.png` beside `kit-dot.json` when supplying files on Pro Kit.
The JSON does not embed the image.

The dot must derive 192 px, 512 px, maskable 512 px and Apple touch 180 px PNGs.
The public demo shows those cuts, plus a 32 px favicon preview.
Derived filenames follow `icon-home-HASH.png`, `icon-large-HASH.png`,
`icon-maskable-HASH.png`, and `icon-apple-HASH.png`, using the full original
SHA-256. Regenerate those assets and update manifest references when the hash
changes, so phones do not keep a cached icon.

Keep artwork within the central 80% diameter circle. The page samples a 128 px
copy, comparing alpha and colour outside that circle with the corner background.
It warns if more than 1% of those outside pixels contain visible artwork.
This is a heuristic: check the round-mask preview too, especially for art on a
flat opaque background. A warning does not block saving.

On iOS, a changed icon usually needs the app removed and re-added to the home
screen. The app consumer remains responsible for its manifest and icon assets.

The dot reads runs, decisions, hosts, cluster state, peers, the board and trace
search through the `hev` binary. Actions such as messaging a peer, replying to
a run, resolving a decision or sending an order use that same source.

hev kit is what you need to make your machine part of a software factory. It
runs as a daemon for collecting traces and dispatching work on a host. It acts
as an admission controller for repos (and probably tools/skills over time).
`brew install hev` gets you everything you need to run a factory. To get the
most out of the factory you'll want headless machines locally or in the cloud.

hev kit is what you need to make your machine part of a software factory.
It's one binary with the tools a factory needs: a daemon that collects traces,
dispatch that sends work to your hosts, and an admission controller that
decides which repos a host accepts (and probably tools and skills over time).
`brew install hev` gets you everything you need to run a factory. To get the
most out of the factory you'll want headless machines locally or in the cloud.

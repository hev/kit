Joining with the one-time invite code, which expires after a few hours, creates a dedicated SSH key, pins the machine's identity so there is no trust prompt, adds an SSH alias and a host entry in your dispatch config. It prints a request containing only your public key, which you send back to Adam; only use a code that came from Adam through a channel you already use with him.

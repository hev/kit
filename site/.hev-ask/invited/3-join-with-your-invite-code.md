Join with the single-use, short-lived invite code Adam sends privately; it creates a dedicated SSH key, pins the machine's identity, adds an SSH alias and a host entry in your dispatch config, and prints a request (containing only your public key) to send back to Adam. Only use codes from Adam through a channel you already trust.

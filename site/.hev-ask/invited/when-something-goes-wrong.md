Troubleshooting table for the managed machine: a missing machine in Tailscale, an expired invitation, an already-joined host, a public-key permission error before acceptance, revoked access, and an order refused because the repo is not admitted. To leave, tell Adam and optionally delete the local key files, SSH config block and dispatch config entry.

Runs on the machine already land in the team trace archive; to add your laptop sessions, bring the daemon up with the team API key and namespace delivered through 1Password. Capture picks up every agent session on that laptop, not only team work, and secret scrubbing is imperfect, so use a work machine or keep other projects off it.

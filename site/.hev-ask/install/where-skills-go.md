Skills install into the home folder: Claude Code and shared agent skills folders, a Codex fallback, pinned team skill copies, team commands and install state. hev skills are stamped and prefixed, user-written skills are never replaced, local edits are kept unless forced, and check and sync report and repair drift; hev init points traces at an existing hev layer archive.

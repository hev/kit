Requirements depend on the machine's job: capturing and searching traces needs only hev, sending work needs hev plus SSH access to the target, and running dispatched work needs Git, clones of the repos, a logged-in Codex or Claude Code, and tmux on macOS and Linux. The GitHub CLI is optional and adds pull request links to runs; Club Kit or Pro Kit share one archive across machines.

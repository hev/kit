Prebuilt release archives exist for macOS and Linux (arm64 and amd64) and for Windows 11 on AMD64; download the one for your platform, verify it against the release checksums and extract the binary onto your PATH. Windows users open a new PowerShell afterwards, and the Windows page covers the scheduled task and dispatch targets.

Skills setup installs version-stamped hev skills for Claude Code, Codex, pi and OpenCode plus the team's skills repo, starts nothing, and can be rerun safely. On dispatch hosts it asks whether the machine is a host or sender, and members get a member skill instead of owner-only ones.

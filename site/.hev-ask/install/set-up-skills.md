Right after installing, run the skills setup, which installs version-stamped hev skills for Claude Code, Codex, pi and OpenCode plus your team's skills repo if configured. It starts no services, is safe to rerun, asks whether a machine is a dispatch host or a sender the first time, and installs the member skill set on laptops that only send to hosts they joined as members.

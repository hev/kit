Sharing one host across a team gives every developer access to its repos, bot identity, credentials, tools, skills and trace archive while each sends work from their own laptop. A host can be a physical machine or VM, each with its own owner, members and admission list, and the host account should be set up like a new hire with only the access it needs and humans approving its work.

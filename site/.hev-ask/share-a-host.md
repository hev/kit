Share one host across a team: it carries the repos, bot identity, credentials, tools, skills and trace archive, and each developer sends work from their own laptop. A host can be a machine or VM, each with its own owner, members and admission list. Treat the host account like a new hire and use a dedicated machine, since the sandbox is the computer.

Sharing one host across a team: the host holds repos, the bot identity and credentials, tools, skills and the trace archive, and developers send it work from their laptops. Hosts can be physical machines or VMs, each with its own owner, members and admission list; treat the host account like a new hire with narrow access and use a dedicated machine for risky autonomy.

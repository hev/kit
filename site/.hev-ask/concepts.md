Defines a factory as a set of machines that take written orders, run coding agents against them and keep a record of every run, with one binary and plain-file state on each machine. Starter Kit is complete for one person in files; for a team, Club Kit or Pro Kit moves traces and the board into one shared archive while everything else stays in files.

A trace is one coding-agent session (prompts, replies, tool calls), and the kit daemon captures every session on a host into a searchable archive by reading the files the harnesses already write. Dispatched work is also grouped into ask-rooted traces shown as a waterfall in the dashboard. Alone, kit keeps the archive on each machine with word search; Club Kit or Pro Kit gives a team one shared archive with hybrid search, reachable from the terminal, a web UI, a terminal browser or an agent skill.

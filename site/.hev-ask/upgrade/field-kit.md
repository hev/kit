Field Kit (early access, not yet open) signs a machine in through a browser login that stores a team kit key, which only talks to kit's API, never exposing storage credentials. Once signed in, sessions go to the team archive with a local outbox when offline, search and the dashboard cover all nodes by meaning and words, the board and peers are shared, billing is for storage and searches, and a first login can import local history without duplicates.

Dispatch has no central scheduler: full hosts queue orders FIFO, with no priorities, per-person limits or moving queued orders, and capacity comes from each sender's config. Memory (traces and the board) is the deliberate exception, shared through one Layer archive, which local setup runs without an account or a team can use hosted, the paid offering.

Factory accounting: what a factory's sessions cost by instance, role and issue against what shipped. It reads operator-written accounting, price, subscription and outcome files rather than traces, works only when the dashboard server is started with a factory directory, and otherwise answers 503. The response covers period totals, per-instance and per-issue breakdowns, subscription-week figures, priced session rows, shipping outcomes, plan usage and notes on how subscription dollars are allocated.

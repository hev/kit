Publishes an HTML canvas or a new version of one: a new canvas opens a thread on the canvas board and an update replies to it while keeping the previous version. The body carries title, summary, tags, base64-encoded files that must include an index page, and poster details, with path and total-size restrictions. Explains how the returned public URL is derived and that published canvases are served sandboxed; the HTML web UI pages are not part of the API.

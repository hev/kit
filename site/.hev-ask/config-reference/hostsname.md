Each host table defines one host by a lowercase name: run locally or via an SSH destination, an optional capacity ceiling, OS, workspace, PATH prefixes, archive namespace for the worker, a harness wrapper, an alternate dispatch config for the supervisor, and environment variable names to forward. Invalid entries stop senders; targets only require their own entry to be valid. Traced workers also get trace environment variables set by the supervisor.

Setup and archive commands: updating a host to the newest build on its channel, installing and checking skills, configuring a hev layer endpoint interactively (not needed on Starter Kit), config file helpers, bucket profiles, joining, leaving and opening a hosted archive, the hev layer pro commands, and managing the capture daemon as a system service on macOS, Linux or Windows.

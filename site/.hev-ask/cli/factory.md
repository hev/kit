Commands for the factory: overview, setting up and stopping capture, daemon status, sending orders from a file or the command line, listing hosts and runs, showing, following logs, attaching, messaging, stopping, reworking, validating, cleaning and amending runs, plus peers, orchestrators, expediting, and board search, posting, replying, voting, serving and canvases. Dispatch subcommands share config, host and JSON options.

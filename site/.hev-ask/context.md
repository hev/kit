Composable context makes explicit which instructions and skills a run gets: you write a recipe listing files in order, kit builds a bundle with the assembled text and a digest, dispatch gives it to the worker and records the digest on the run and its sessions, so you can find and compare runs given the same context. Bundles contain only what the recipe lists.

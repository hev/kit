Composable context makes explicit which agent instructions and skills a run gets. You write a recipe listing instruction and skill files in order, whole or narrowed to sections; kit builds it into a bundle with a digest identifying exactly that content, dispatch gives it to the worker and records the digest, and the worktree's instruction files match the recipe while the worker runs. There are no hidden defaults, and you can later find and compare every run given the same context.

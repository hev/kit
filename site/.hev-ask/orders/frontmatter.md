Most orders need a run name (lowercase, digits, hyphens; it names the branch, run directory and trace tag), a host from your config, a repo with an origin remote, and a harness. Also set a timeout, a reply address if notifications route somewhere, browser validation for UI work, a context recipe to pick instructions and skills, and a trace to join ongoing work.

Threads are grouped into default boards: memos for standing guidance, research for findings (the default), learnings for costly lessons, tooling for machine and tool issues, floor for status and handoffs, canvas for published HTML pages, watercooler for everything else, and feedback. A command lists boards with thread and post counts.

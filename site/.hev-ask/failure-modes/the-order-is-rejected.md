An order is parsed on your machine and again on the host, and nothing is created when parsing fails. Lists each parse error and its cause: a missing Acceptance section, missing or unclosed frontmatter, unknown, duplicate or empty fields, nested YAML, an invalid name, a missing repo, and invalid harness, validation, timeout, base or host values.

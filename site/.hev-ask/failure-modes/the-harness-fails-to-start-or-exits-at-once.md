hev doesn't verify the harness is installed or signed in; a missing program fails the run with a not-found error, and an unsigned-in harness exits with its own error in the log. On Unix the worker inherits a fixed set of environment variables from the admitting process, extendable per host; on Windows use a wrapper for credentials. Sign the harness in as the SSH user and rework.

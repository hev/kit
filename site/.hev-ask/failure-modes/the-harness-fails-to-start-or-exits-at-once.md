hev does not check that the harness is installed or signed in; a missing executable fails the run with the error in the result, and a signed-out harness exits with its own error in the log. Workers inherit a fixed set of environment variables plus configured extras on Unix, while Windows uses a wrapper for credentials; sign the harness in as the SSH user.

Because harnesses read instruction files from the worktree themselves, dispatch puts each one there in the form the recipe gives it for exactly as long as the harness runs: narrowed, whole, excluded (removed), or left full when it has uncommitted changes. Only the worker's own worktree changes; replaced files are hidden from Git so they cannot be committed by accident, and they are restored when the harness exits or on the next attempt. The worker is told which files were narrowed or excluded and how to restore one before editing it; an unrestored edit is saved in the run record and reported as a warning.

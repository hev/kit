Planning reads an order, assesses its repository and writes a starting recipe with every instruction file, agent and skill whole and the order body as the task, plus an inventory of sizes, sections and findings and a review page. It cuts nothing and calls no model, so choosing what the task needs is up to you; with no instruction files it reports there is nothing to narrow. Keep whole any instruction file the order asks the worker to edit.

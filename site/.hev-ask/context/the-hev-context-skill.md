A bundled skill lets an agent that dispatches for you do the context review with you: it plans, proposes a narrowed recipe with a reason for each cut, checks it builds, and shows one screen of what is kept, dropped and the size change for a yes or a correction. It then dispatches with the carried recipe and reports the digest; it never edits a repository's instruction files, and you can tell it to skip the review. Dispatch itself never asks anything.

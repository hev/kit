The bundle is not everything the agent sees, since harnesses still load instruction files, user settings and system prompts on their own; the digest proves what dispatch gave, not what was read. Discovery is project-local, linked files are not added automatically, validators get no bundle, recipes only list files, and every host must support context or it refuses the order.

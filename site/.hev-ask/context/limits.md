Limits of composable context: the bundle is not everything the agent saw, since harnesses still load user-level settings, their own system prompts and worktree files discovery does not cover. A digest is a reproducibility handle, not proof of what the harness read. Discovery is local and literal, validators get no bundle, recipes can only list files, and a target whose version lacks context support refuses such an order rather than running without it.

The bundle is not everything the agent saw: harnesses still load instruction files, skills, user settings and system prompts on their own. A digest proves what dispatch gave, not what the harness used; discovery is local and literal; validators get no bundle; recipes list files only; and every host must support context or it refuses such orders.

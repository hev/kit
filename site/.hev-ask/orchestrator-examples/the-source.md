A source plugin answers a describe call, an events call that prints one JSON event per line plus a final cursor, and an optional acknowledge call. The page gives a starter Python source for Linear issues with a given label and shows two ways to supply the API key without storing it in the spec: a wrapper that reads it through the secrets cache at each call, or passing a named environment variable only to the source.

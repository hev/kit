The source plugin protocol: a describe call, an events call that prints one JSON event per line plus a final cursor line, and an optional ack; the previous cursor arrives via an environment variable. Includes an example Linear source script and a wrapper that fetches the Linear API key from 1Password per call via the secrets cache, or alternatively passes a named variable from the supervisor's environment to the source only, so the key never lives in the spec.

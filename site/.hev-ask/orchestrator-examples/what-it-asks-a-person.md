With the model off, the intake loop writes no prose, and kit tells the reply address in one line on start, stop, run caps, rejections and reconcile needs. Each run's template carries a reply so the notify command hears when it ends. For one summary, add a second report-only orchestrator over the same scope, whose spec is provided.

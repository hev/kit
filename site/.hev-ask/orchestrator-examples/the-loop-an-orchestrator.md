The Gauntlet orchestrator spec runs the loop without judging the work, since only the validator's verdict counts. It starts validation if pending, reworks from the validation on a fail, writes a goal-met file on a pass, stops and reports on needs-review, and never edits the Acceptance. Budget and lifetime are small.

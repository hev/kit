The Gauntlet orchestrator spec manages a single named run with say, notify, rework and validate authority and a one-at-a-time budget. Its brief: never judge the work itself; validate when validation is pending, rework from the validation verdict on failure, report the head SHA on a full pass, stop and report when the run is needs-review, and never reinterpret the Acceptance.

Acceptance for the swarm's ship role, plus how to write and run the proposed swarm file, which only exists on an unmerged draft PR branch. Bringing it up compiles an orchestrator scoped to its runs with a budget and lifetime; crashed or stalled builders restart a limited number of times, and the stop is daily runs and lifetime until a total run cap arrives.

The intake orchestrator spec: a deterministic loop with the model turned off, scoped to one issue prefix and repo, dispatch-only authority, a Linear source with a label filter, one rule that starts in dry-run, a small budget and a pause file. It pairs with an order template that names the issue and tells the worker to stop and report if the issue is unclear or too large.

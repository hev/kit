kit never signs in to Azure interactively; set one credential in the daemon's environment: managed identity on a VM, Arc server or App Service, workload identity on Kubernetes, a service principal with certificate or client secret (preferably via a secret reference), or an existing Azure CLI login. Auto-selection order is described, the metadata endpoint and CLI are used only when named, callers need the same credential, Azure Stack Hub needs extra settings, and tokens stay in memory.

The cache serves a caller only when both hold the same credential, compared by fingerprint: the same 1Password token from the environment or token file, or the same Azure credential. A host with the token in the default file needs only a daemon restart; hosts without the capture daemon can run a secrets-only endpoint as its own service, environment variables relocate the endpoint, read log and cooldown file, and restarting the cache sends no request because it refills on demand.

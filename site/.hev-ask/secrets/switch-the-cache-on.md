The cache serves a caller only when both hold the same credential: the same 1Password token from the environment or token file, or the same Azure credential. A host with the token in the default file just restarts the daemon; a different file is set in a service drop-in, and hosts without the full daemon can run a standalone secrets-only service. Covers endpoint, cache bypass, read log and cooldown environment overrides, and notes older daemons refuse Key Vault references.

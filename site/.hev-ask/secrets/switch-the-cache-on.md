The cache serves a caller when both hold the same 1Password token, from the environment or the private token file; a host using the default file just needs hevd started, and a host without hevd can run a standalone secrets-only service via the provided systemd or launchd units, which updates restart. Environment settings move or disable the endpoint, read log and cooldown file, or skip the cache for tests. The daemon checks credentials per store using only SHA-256 fingerprints, so a caller with different Azure settings still gets 1Password reads served; upgrade hevd before using Key Vault references.

The cache serves a caller when both hold the same credential, for 1Password the same service-account token from the environment or the token file; a host with the token in the default file needs no configuration, otherwise point hevd at the file with a systemd drop-in. Hosts not running hevd can run a secrets-only daemon as its own systemd or launchd service. Environment variables can move the endpoint socket or Windows named pipe, disable the cache for tests, and move or disable the read log and cooldown file; only credential fingerprints cross the endpoint, and without an endpoint each process pays for its own request.

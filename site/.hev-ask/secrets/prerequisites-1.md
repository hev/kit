Prerequisites for Azure Key Vault: a vault, the secret names, an identity with the read role, and one supported credential for it, plus hev with hevd running and upgraded before any caller uses Key Vault references. Neither the 1Password CLI nor the Azure CLI is required unless you choose the Azure CLI credential.

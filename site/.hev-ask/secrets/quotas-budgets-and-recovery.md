1Password service-account daily allowances are shared across all tokens and machines by plan tier, so kit reserves each real request in a durable local ledger with default host limits per day, hour and per-caller minute; cache hits are free and a refused read exits with a distinct budget status. A private policy file tunes limits, a one-time override, threshold notifications and which single host meters the account's quota; status is free unless you explicitly refresh quota, and you should never delete the ledger to reset spending.

Steps to enable the secrets cache in the Windows capture scheduled task: install the binary at a permanent path, configure the manager and DPAPI settings in a protected launcher script, repoint the task's action at that launcher while preserving its identity and triggers, then start and verify the daemon is up with the protected-file credential. Illustrative before-and-after shows thirty separate reads collapsing to one real request with cache hits within the TTL; restarts empty the cache, and on-host verification is still required.

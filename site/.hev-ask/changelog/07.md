Version 0.7, not yet released, adds composable context (orders naming a context recipe that is built into a recorded bundle with a digest), ask-rooted traces shown as a waterfall in the dashboard's Asks view, and file-based traces and board with no key so setup starts nothing in Docker. The local Postgres lane is retired, and hosts still configured for it are told how to stop its containers.

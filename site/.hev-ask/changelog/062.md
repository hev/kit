Members can add and remove repos within owner-approved organizations, with the host cloning safely using its own credentials. Added one-step skills setup for several harnesses (with member-specific skills), run notices for members pulled from the host, OpenCode capture, per-host concurrency classes, and keeping watch source secrets confined to their plugin.

Version 0.6.2 (November 8, 2026) lets members add and remove repos within organizations the owner lists, with a per-member grant and host-side cloning under strict limits. It also added a one-step skills setup for several harnesses, held run notices that members pull from a host, OpenCode capture, per-class concurrency caps on hosts, tighter handling of watch-source secrets, and shared-host docs for owner and member roles.

Release notes for kit 0.6.1 (November 6, 2026): shared hosts with invited teammates, a first-in-first-out dispatch queue, deterministic watches on tracker statuses and email, the memory-only secrets cache with rate-limit backoff and status, pinned team skill sources, native peers, and renamed hev layer environment variables with the old names still accepted. A daemon no longer falls back to a built-in 1Password reference for the layer key.

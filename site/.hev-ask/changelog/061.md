Version 0.6.1 (November 6, 2026) added shared hosts where invited teammates get dispatch-only access that can be revoked, a first-in-first-out queue on full hosts instead of refusals, deterministic watches on tracker statuses and an email inbox, a memory-only secrets cache in the daemon, team skill sources, and renamed hev layer environment variables with the old names still working with a warning.

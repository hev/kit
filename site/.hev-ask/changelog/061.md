Version 0.6.1 added shared hosts with invited members whose keys can only dispatch, a first-in first-out dispatch queue for full hosts, deterministic watches on tracker statuses and email, a daemon secrets cache, team skill sources, peers delivery over restricted keys, and renamed hev layer environment variables with the old names still accepted.

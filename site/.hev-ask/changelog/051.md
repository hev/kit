Version 0.5.1 (October 25, 2026): dashboard stats load on their own, the bare command prints a read-only overview, and capture keeps instruction versions, commit, PR and workflow evidence and native PI traces. It introduced a resource-first CLI that was later removed in favor of dispatch and orchestrate. Version 0.5.0 was tagged but never published because of a build toolchain mismatch.

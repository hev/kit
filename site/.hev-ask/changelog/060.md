Version 0.6.0 (November 5, 2026) introduced the software-factory tools: dispatch of orders to hosts over SSH with supervised workers and run records, inline orders and messages, browser validation, per-host launch settings, repo admission, the board, plugins, orchestrators, amendments, repeating orders, expediting, native peers and target-owned capacity. It also added Windows capture, better summaries and skill capture, broader install coverage across macOS, Linux and Windows, bundled skill checks, and a read-only board mode.

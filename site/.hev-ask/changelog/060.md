Version 0.6.0 introduced the software factory tools: dispatch to hosts over SSH with run records, inline orders and messaging, browser validation, per-host launch settings, repo admission, the board, plugins, Windows capture, orchestrators, native peers, amendments, repeating orders, expediting, target-owned capacity, multi-platform packaging, skill drift checks and a read-only board mode.

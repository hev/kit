Orchestrator commands dry-run and apply specs, start ad hoc ones, list, show, view round logs, pause, resume, wake, stop and hand off to another owner. State lives in a per-orchestrator directory on its host with spec, checkpoint, inbox and rounds; waking never overlaps a running round.

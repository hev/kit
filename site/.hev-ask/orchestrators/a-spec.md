An orchestrator spec is a Markdown file whose frontmatter sets the goal, mode (once or loop), cadence, end condition, maximum lifetime, who to reply to, which runs it manages, its authority verbs and its budget. The body is its standing brief. There is no merge authority. The page includes a ready prompt that has an agent write and dry-run such a spec.

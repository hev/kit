Orders that opt into browser validation get an independent validator after finishing, run on the configured validation host at the implementer's pushed head, checking each acceptance item in a real browser with screenshots and a verdict, never editing code. Validation can be started by hand, must use a different host and harness/model pair, and failed verdicts can feed rework; the same item failing twice marks the run as needing review.

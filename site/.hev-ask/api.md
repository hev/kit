hev kit has local HTTP APIs, served on your own machines on every tier (the trace dashboard API and the board API), and the hosted Field Kit API on hevkit.com, which is early access and not yet deployed. The CLI is a client of these APIs; the APIs are meant for your own scripts, dashboards and tools.

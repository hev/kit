A host is a machine that runs workers: the laptop you type on, or a headless machine such as a closet box, spare Mac or cloud VM that runs many workers and keeps going overnight. Every machine that sends or receives work has a dispatch config with one table per host it knows about, and a host exists for a sender when its config names it. Sharing a host with teammates is covered separately.

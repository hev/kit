The quickstart takes one macOS or Linux laptop from nothing to a finished, searchable agent run, with the laptop both sending the order and running the worker. It needs Git, tmux, Codex or Claude Code logged in, and a disposable repository clone under the workspace directory with an origin remote; kit alone needs no account, key or Docker. Team members joining a host and Windows users have separate pages.

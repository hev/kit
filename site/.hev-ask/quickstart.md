Takes one laptop from nothing to a dispatched agent run you can search: install, start the daemon, configure a local host, write and dispatch an order, watch it, search its trace and clean up. Needs Git, tmux, and Codex or Claude Code logged in, plus a repo clone with an origin remote. It works with no account, key or Docker, and Windows has its own page.

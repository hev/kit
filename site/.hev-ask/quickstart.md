Takes one macOS or Linux laptop from nothing to a finished, searchable agent run, with the laptop both sending the order and running the worker. It needs Git, a logged-in Codex or Claude Code, tmux and a repo clone with an origin remote you are happy to let an agent change; no account, key or Docker is required.

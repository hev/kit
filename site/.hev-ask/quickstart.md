Quickstart takes one laptop from nothing to a finished agent run you can search: install hev, start the daemon, dispatch one order to your own machine and search its trace. The laptop is both sender and worker, so it needs Git, Codex or Claude Code, and tmux; no account, key or Docker. Teams should start with Join a cluster.

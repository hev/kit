Onboarding page for someone given a managed agent machine set up by Adam on a private Tailscale network, preloaded with hev kit, their repos and skills. You send work from your own laptop, agents run on the machine under an identity set up for your organization, and you receive a Tailscale invite, a hev invite code and a trace-archive API key.

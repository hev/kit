Invited users connect to a managed agent machine Adam set up on a private Tailscale network, with hev kit, repos and skills installed. You send work from your laptop; agents run on the machine and nothing on your laptop is shared. You receive a Tailscale invite, a kit invite code and a trace archive API key.

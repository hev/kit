Adam has set up a managed agent machine for you on a private Tailscale network with hev kit, your repos and skills, which you send work to from your laptop without sharing anything from it. You need Tailscale plus a Tailscale invite, a hev kit invite code and a team archive API key from Adam; setup takes about ten minutes.

Hosts on 0.6.2 or earlier lack hev update and do not understand the request, so each must be moved by hand once, including the dispatching host. Download the newest edge archive and checksums from the releases page, verify the checksum, unpack, and install it; afterwards one command can move all hosts. Includes shell snippets for Linux and macOS.

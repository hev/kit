Without a hev layer key, traces live in files on the machine that captured them, one per session with a word index, needing no endpoint, account or Docker, and the location can be moved. With a key, traces go to one shared namespace and nothing is written locally; a configured key that cannot be read is an error, and kit never silently falls back to files on a machine set up for hev layer. Status shows where the daemon stores traces versus what your shell would use and flags a mismatch, which happens when only the service has the key, so shells and dispatched workers need it too. The file archive is never pruned, takes roughly 400 MB per 1,000 sessions, and its index can be deleted safely because it is rebuilt.

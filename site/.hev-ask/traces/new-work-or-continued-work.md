Whether work starts or continues a trace depends on how it was sent: a fresh dispatch starts one, passing a trace ID continues it, rework/retry/say/amend/validate continue the run's trace, dispatch from inside a traced worker nests under it, and orchestrator rounds without a trace are untraced. To link a second order, copy the first run's trace ID; the sender strips the trace key before the host sees the order.

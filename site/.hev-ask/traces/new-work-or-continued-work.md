Whether an ask starts a new trace or continues one depends on how work was sent, never on the order name: a plain dispatch starts a new trace, passing a trace ID continues it, rework, retry, say, amend and validate continue the run's trace, dispatch from inside a traced worker continues the worker's trace, and orchestrator rounds without a trace to inherit are untraced. To send a second order as part of the same work, copy the first run's trace ID from its receipt and pass it when dispatching.

kit decides whether an ask starts a new trace or continues one from how the work was sent, never from the order's name. A plain dispatch starts a new trace; passing an existing trace ID, reworking, retrying, messaging, amending or validating a run, or dispatching from inside a traced worker continues one; orchestrator launches with nothing to inherit are recorded as untraced with a reason. To send a second order as part of the same work, look up the first run's trace ID and pass it along; the sender strips the trace key from the order before the target sees it.

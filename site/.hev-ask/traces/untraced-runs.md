A run without a trace is labelled either before tracing (no trace fields at all; history from before ask-rooted traces, shown neutrally) or untraced (deliberately recorded with a reason, such as orchestrator launches, source-event runs or swarm units). Pre-tracing runs are hidden by default with a count and a URL control to show them.

Explains the design: the machine running the work holds the credentials, clones and risk, so policy lives there and a dispatch request can only ask. The trade-offs are that the list must be edited on every host with no central push, older versions reject the unknown config table so hosts must be upgraded first, and only the repos list is read today though lists for tools and skills are planned.

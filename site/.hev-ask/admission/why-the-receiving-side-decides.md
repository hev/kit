Policy lives on the machine that runs the work because it holds the credentials, clones and risk; if senders carried it, any sender with SSH access could widen it. The trade-off is editing the list on each host, with no central push. Older hev versions reject the admission table as an unknown key, so upgrade hosts first; only repo lists are read today, with tool and skill lists planned.

Describes the version 1 config file format for the team's installable, voice-first mobile web app (a PWA built on hev dots). Club Kit admins edit it through the mobile app settings and Club Kit hosts the app; Pro Kit users supply the file directly and run the app in their own cloud beside hev layer.

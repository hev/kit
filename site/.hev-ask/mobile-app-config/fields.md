Reference for every required field in the mobile app config: format version, app name, two-part wordmark, operator name, accent colour, spoken voice, allowed sign-in emails, optional host list, optional icon with its hash, and a live-actions switch. Unknown fields are rejected, a JSON Schema carries the same rules, and live actions are off (dry-run) by default and still need a spoken read-back and confirmation.

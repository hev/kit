Coding agents can be pointed at an index file listing every docs page with its description and a link to its Markdown, or at a single file with the full text of all pages; each page's Markdown is also available at its own URL. Code blocks that do something have an Agent prompt tab holding a paste-ready prompt with a link to the relevant section.

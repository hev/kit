Introduces three copyable orchestrator specs: an intake loop that turns tracker issues into orders, a release coordinator that moves a release train toward a publishable draft, and a Gauntlet loop that reworks one piece of work until an independent critic passes it. All pass the dry-run and schema check; none has merge authority, so a person always merges.

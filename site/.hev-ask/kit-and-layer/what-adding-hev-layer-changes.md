Compares kit and kit + layer: per-machine file archive versus one shared namespace, word search versus hybrid search across machines, a dashboard with grades and hosted access, a shared board, and evals only with layer. Dispatch, peers, admission, host access and secrets remain files either way, and kit alone is not a trial.

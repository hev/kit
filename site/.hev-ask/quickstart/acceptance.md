The example acceptance criteria are a README Development section with the test command, committed on the run's branch. Repo is a directory under the workspace, base defaults to main, and the harness can be codex or claude. Workers run with approvals and sandbox disabled and by default push and open a draft pull request, so use a repository and machine you are comfortable handing to an agent.

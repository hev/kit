Order parse errors cover missing or unclosed frontmatter, non-flat lines, unknown or duplicate keys (including issue with its alias), quoting and scalar problems, empty fields, missing Acceptance, and invalid timeout, name, repo, harness, validation, base or trace. A bad context recipe fails on the host before the worker starts.

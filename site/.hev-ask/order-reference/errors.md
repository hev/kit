Table of order parser error messages and their causes: malformed or unclosed frontmatter, unknown, duplicate or empty keys, quoting problems, a missing Acceptance section, and invalid timeout, name, repo, harness, validation, base, context recipe or trace values. A run whose context recipe is missing or invalid fails on the host before the worker starts.

Overview of joining a team's shared host as a member: the host already has the repos, bot identity, credentials and agent tools, and your laptop only sends work to it. Agents run under the host's accounts, nothing on your laptop is shared, and you need private network access, an invite code and optionally a team trace archive key and namespace from the owner.
